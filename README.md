# WORLD DOMINION — Android 1.2

نسخه بازطراحی‌شده برای اندروید با صفحه شروع سینمایی، ساخت هویت ملی و نقشه جهانِ سبک‌سازی‌شده.

## تغییرات این نسخه
- صفحه شروع تمام‌صفحه با لوگوی WD، کره سه‌بعدی‌نما، انیمیشن ملایم و منوی مستقل بازی
- فونت‌های آفلاین Noto Sans Arabic برای فارسی و Inter Display برای تیترهای لاتین
- انتخاب از میان ۱۹۴ کشور یا ساخت کشور مستقل از صفر
- تنظیم نام کشور، پایتخت، پرچم، رنگ ملی، نوع حکومت و گرایش فرهنگی
- رنگ ملی و هویت انتخابی در بازی و ذخیره بازی نگهداری می‌شوند
- نقشه تولیدشده با شکل کلی قاره‌های جهان به‌جای لکه‌های تصادفی؛ بازیکن محل تأسیس پایتخت را روی خشکی انتخاب می‌کند
- شبیه‌سازی آفلاین کشورها، اقتصاد، جمعیت، بودجه، کابینه، سیاست، دیپلماسی، پژوهش و رویدادها

## اجرای محلی
- Node.js 20 و JDK 17
- `npm install`
- `npm test`
- `npx cap add android` (فقط بار اول)
- `npx cap sync android`
- `cd android && ./gradlew assembleDebug`

## ساخت APK با GitHub
Workflow با هر push یا اجرای دستی از بخش Actions اجرا می‌شود. تست‌های منطقی قبل از کامپایل اجرا می‌شوند و APK دیباگ در Artifacts قرار می‌گیرد.

## وضعیت نقشه و جهان
نقشه فعلی یک نقشه جهانیِ تولیدشده با قاره‌های قابل‌شناسایی است، اما هنوز مرزهای دقیق سیاسی و جغرافیایی کشورهای واقعی را نمایش نمی‌دهد. انتخاب یک کشور واقعی در این نسخه هویت و نام کشور را تنظیم می‌کند؛ محل شروع همچنان با انتخاب بازیکن روی نقشه انجام می‌شود. حالت آنلاین/جهان مشترک هنوز جزو این بیلد نیست.
