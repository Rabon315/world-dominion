# WORLD DOMINION — Android

نسخه آفلاین و فارسی بازی استراتژی کشور‌داری. هسته فعلی شامل نقشه قلمرو، هوش مصنوعی رقبا، اقتصاد، سیاست داخلی، کابینه، دیپلماسی، پژوهش، رویدادهای پویا، ذخیره‌سازی محلی و تقویم بازی است.

## اجرای محلی
- Node.js 20 و Android Studio / JDK 17 برای ساخت اندروید
- `npm install`
- `npm run test:logic`
- `npx cap add android` (فقط بار اول)
- `npx cap sync android`
- `cd android && ./gradlew assembleDebug`

## ساخت APK با GitHub
با push یا اجرای دستی workflow به نام **Build APK**، فایل APK دیباگ در بخش Artifacts قرار می‌گیرد. این workflow تست منطقی شبیه‌سازی را پیش از build اجرا می‌کند.

## قابلیت‌ها
- اقتصاد: خزانه، مالیات، تولید ناخالص داخلی، تورم، بدهی و بیکاری
- جمعیت: جمعیت پویا و رضایت عمومی
- بودجه: تخصیص به درمان، آموزش، زیرساخت، دفاع، رفاه، علم و اداره دولت
- حکمرانی: کابینه، احزاب، انتخابات، استان‌ها و رویدادهای تصمیم‌محور
- دیپلماسی: تجارت، اتحاد، آتش‌بس و تحریم
- فناوری: درخت پژوهش و اثر بر شاخص‌های کشور
- زمان: تقویم روز/ماه/سال، توقف و سرعت‌های مختلف
- ذخیره‌سازی: ذخیره دستی و خودکار روی دستگاه

**ملاحظة:** نقشه این نسخه یک نقشه استراتژیک تولیدشده درون بازی است، نه نقشه جغرافیایی دقیق مرزهای واقعی کشورها. حالت آنلاین و سرور مشترک در این نسخه پیاده‌سازی نشده‌اند.
