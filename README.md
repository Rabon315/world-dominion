# World Dominion APK
1. در github.com یک مخزن (repository) جدید بساز.
2. همه‌ی فایل‌های این پوشه را (با پوشه‌ی .github) آپلود کن.
3. به تب Actions برو، Build APK را اجرا کن (Run workflow).
4. بعد از چند دقیقه از پایین صفحه‌ی اجرا، فایل WorldDominion-APK را دانلود کن؛ داخلش app-debug.apk است.
5. APK را روی گوشی نصب کن (اجازه‌ی نصب از منبع ناشناس لازم است). بازی خودکار افقی است.
